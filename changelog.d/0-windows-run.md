### Added
- `openmoat run` on native Windows (preview): the agent starts suspended under a write-restricted token, in a job object that ends every process it started when the run ends and lets none leave, and both are read back before it runs. Writes outside the project, the run's temp directory and `--write` paths are refused, and `.git`, `.moat` and the CI and editor folders at the project's top too. Reads are not restricted and the network is held only by the proxy variables; the boundary record (`proxy_variables`), `--print-boundary` and `openmoat doctor` say so, and the protection score counts both as missing (at most 55/100 on Windows). Batch files such as npm `.cmd` shims are not started; `openmoat mcp wrap` keeps servers out of the tier unless `--sandbox` is given (ADR-115) ([#0](https://github.com/crocodile-labs/openmoat/pull/0)).
