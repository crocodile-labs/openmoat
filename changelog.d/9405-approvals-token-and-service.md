### Security
- `openmoat approvals connect` no longer shows the bot token as you paste it: the terminal's echo is off while the token is read, Ctrl-C cancels and puts the terminal back, nothing prints it back, and a token piped into the command is refused (`--credential-file` reads one from a file; on Windows it is the only way) ([#9405](https://github.com/crocodile-labs/openmoat/pull/9405)).
- `openmoat approvals install` keeps `openmoat approvals listen` running after the terminal closes, as a launchd user agent (macOS) or systemd user unit (Linux) started at login, restarted when it fails, logging owner-only to `~/.moat/logs/approvals.*.log`; `openmoat approvals uninstall` and `openmoat uninstall` remove it, and `approvals status` and `doctor` report it. The service's `listen --service` needs no terminal but still refuses an agent among its parents, a service file that differs from what `install` wrote, an environment that changes its TLS roots or loads a library, and a start the service manager did not make; only one listener runs at a time, and on Linux it cannot be attached to by other processes (ADR-094) ([#9405](https://github.com/crocodile-labs/openmoat/pull/9405)).
