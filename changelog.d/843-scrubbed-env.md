### Security
- `openmoat run` can pass on only an allowlist of the environment it starts from, so a credential in your shell reaches neither the agent nor anything it starts: `sandbox.env: scrubbed` in your policy for every run, or `openmoat run --scrub-env` for one. The list keeps what programs and builds need (`PATH`, `HOME`, locale, toolchain locations such as `JAVA_HOME` and `CARGO_HOME`), the agent's own variables from its spec, `sandbox.env_allow` and `--env` names. A brokered secret's variable now holds its placeholder instead of being removed, so a tool that needs it set starts and sends the placeholder. `openmoat run --print-boundary` and the run's audit row name what passes and what is withheld, names only; `openmoat doctor` lists what a run here withholds. Off unless you turn it on for now; `require.run: full-boundary` still turns it on ([#843](https://github.com/crocodile-labs/openmoat/pull/843)).
