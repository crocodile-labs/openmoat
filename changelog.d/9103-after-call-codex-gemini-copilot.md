### Security
- Injected input (ADR-057) is now linked for Codex, Gemini CLI and GitHub Copilot CLI too: `openmoat init` adds each one's after-call hook (`PostToolUse`, `AfterTool`, `postToolUse`) beside the pre-call one, so a host, path or command that a fetched page, an issue or an MCP result named makes a later call that uses it need review (`injected-input`). The payloads follow what the weekly latest-agents run recorded from each real agent. GitHub Copilot CLI's entries now name their event (`openmoat guard --event`), since its payloads name none: a payload is a report of what a call returned only when the `postToolUse` entry sent it. After upgrading, run `openmoat init` once; in Codex, trust OpenMoat's new hook in `/hooks` ([#9103](https://github.com/crocodile-labs/openmoat/pull/9103)).
