### Security
- Running a file the same agent session wrote now asks where no OS sandbox from OpenMoat holds the command (`session-written-code`, ADR-039): on OpenClaw, GitHub Copilot CLI, pi, Gemini CLI, OpenCode and Hermes Agent, and on Claude Code and Cursor on native Windows or with their sandbox not in place. Before, an agent could write `x.py` and run `python3 x.py`, `node x.js` or `go run x.go` (allowed) or `bash x.sh`, `ruby x.rb` or `perl x.pl` (deferred), and the script could read `~/.ssh/id_rsa` through a path it builds. Every interpreter form (`python3 -u x.py`, `python -m tool`, `node -r ./x.js`, `deno run`, `bun`, `php -f`, `pwsh -File`, `npx tsx`, `sh < x.sh`, `source x`), a program named by a path (`./x`, `bin/x`), and inline code importing a module the session wrote (`python3 -c 'import tool'`) count, through `env`, `time`, `bash -c` and the other wrappers; so do shell writes (`echo … > x.sh; bash x.sh`). Claude Code, Codex and Cursor with their sandbox in place on macOS and Linux, and `openmoat run`, are unchanged. A session grant (`openmoat allow --last`) answers it until the session rewrites the file; OpenCode 1 denies it with that hint. Files the session did not write (`python manage.py`) and test runners (`pytest`, `npm test`, `cargo test`) keep their verdict. The audit log moves to schema 5, which records each session's writes, bounded to 30 days and 100 000 files ([#672](https://github.com/crocodile-labs/openmoat/pull/672)).
- Inline interpreter code that opens files, connects, reads the environment or runs programs with text it builds at run time now asks (`opaque-code`), with `-c`/`-e` and in a here-document alike: `python3 -c 'print(open(os.path.expanduser("~/.s"+"sh/id_rsa")).read())'`, `node -e "require('fs').readFileSync(process.env.HOME+'/.ss'+'h/id_rsa')"` and `perl -e 'open F,"$ENV{HOME}/.s"."sh/id_rsa";print <F>'` deferred before. `python3 -c 'print(1+1)'`, `node -e 'console.log(2)'` and code that hands those APIs literal text keep their verdict ([#672](https://github.com/crocodile-labs/openmoat/pull/672)).
