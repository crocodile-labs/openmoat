### Security
- Data labels by source (preview, ADR-126): session taint now keeps where data came from (`web`, `mcp:<server>`, `secret`, `private`, `external`, …), and every later call that can send data out, or writes a file that runs later, carries a `@data-flow <label> <sink> <target>` atom that deny and review rules name, so a result the model reworded still counts. The default policy's new `data-flow` review holds an MCP tool that acts after another MCP server's result; `openmoat policy lint` warns when an allow or defer group names the atom ([#862](https://github.com/crocodile-labs/openmoat/pull/862)).
