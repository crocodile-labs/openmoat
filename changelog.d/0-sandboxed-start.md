### Added
- `openmoat init` can make typing a hook-only agent's command (`gemini`, `opencode`, `hermes`, …) start it in `openmoat run`'s sandbox, if you say yes at the terminal (the default is no; only on macOS 13 and later and Linux): it writes a shim per agent in `~/.moat/bin` that runs `openmoat run` around the real program by absolute paths, and two lines in your shell's start-up file that put that folder first on `PATH`, after a backup; `d` shows both first, and for a shell it does not know it prints the line for you to add. The shims are pinned by the lock; `openmoat status` and `openmoat doctor` say whether each agent starts sandboxed in the current shell, and `openmoat uninstall` removes the shims and the lines (ADR-106) ([#0](https://github.com/crocodile-labs/openmoat/pull/0)).
