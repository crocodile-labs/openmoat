### Security
- A file you name with `@` in a Claude Code prompt is now read through OpenMoat's hook: `openmoat init` sets `CLAUDE_CODE_DISABLE_FILE_MENTIONS=1` in the `env` of your Claude Code `settings.json`, so Claude Code (2.1.299 or later) reads the file with its file tools instead of inserting it with no tool call. A secret named that way is denied like any other read of it. An install without the variable is reported as needing `openmoat init`; `openmoat uninstall` takes it out ([#822](https://github.com/crocodile-labs/openmoat/pull/822)).
- Grok Build and the Devin CLI run the hooks in Claude Code's settings files with their own tool names, which OpenMoat's Claude Code hook used to leave unchecked. Such a call is now checked for every path, URL and command its arguments name, and a call that needs review is denied with how to approve it, since neither agent asks the person (ADR-097) ([#822](https://github.com/crocodile-labs/openmoat/pull/822)).
