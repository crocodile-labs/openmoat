### Added
- A call held for review can be approved from your phone: `openmoat approvals connect telegram` connects a Telegram bot you made, `openmoat approvals allow telegram:<user-id>` names who may approve, and while `openmoat approvals listen` runs each review is sent there with Approve and Deny buttons. An approval lets that exact call (agent, session, folder, command or file and its content, and the rules that held it) run once, within 5 minutes by default; a deny is never sent, and every failure leaves the review as it was. `openmoat approvals status`, `test`, `remove` and `disconnect` complete it; nothing changes without a channel. Channels are built to be added one folder at a time: each declares what it can do, and OpenMoat shapes the message to it (buttons, or reply codes to send back, and Deny only when a channel cannot show the whole call); approver ids carry the channel's name, so the same user number on two services never counts twice. docs/APPROVALS.md says how to add one (ADR-078) ([#783](https://github.com/crocodile-labs/openmoat/pull/783)).
