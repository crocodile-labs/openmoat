### Changed
- A `session-taint` ask is answered once per file: after you approve the agent's `Write`, `Edit` or `MultiEdit` of a protected file in a session that read untrusted content, later writes and edits of the same file in that session are allowed until the session reads untrusted content again (the reason names the earlier write). The evidence is the file itself, which must hold what the approved call leaves (for an edit, the file with its replacements applied) and not what it held before, so a declined write, a write of the file's own content, an edit Claude Code would refuse, a patch or shell write, another file or another session still ask (ADR-048; the audit database gains a column and migrates on first use) ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- A `curl` or `wget` download that sends nothing (`curl -o FILE URL`, `curl -O URL`, `wget -O FILE URL`, `wget URL`) is a `fetch` of the URL plus a write of the file: an unlisted host defers to the agent's own prompt like `WebFetch`, and the file is decided by the path rules (`curl -o ~/.zshrc …` is denied by `shell-rc`, `curl -o ~/.local/bin/x …` asks, a project file is allowed). `-q`, `--no-config --no-netrc` and `--max-redirect=0` are no longer required and redirects are followed; a download that sends data, uses `.netrc` or `--location-trusted`, or writes a file the line does not name stays `net`. Setting `CURL_HOME`, `XDG_CONFIG_HOME`, `WGETRC` or `SYSTEM_WGETRC` is denied by `env-poison`, since it moves the configuration files that could turn such a download into an upload ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- New allow group `openmoat-readonly`: an agent may run `openmoat --help`, `-h`, `help`, `--version`, `-V`, `<command> --help`, `policy lint FILE`, `policy check …` and `demo` (also as `moat` and by path, such as a `target/debug/openmoat` build), which read no state and change nothing; `kernel-self` still denies every other person-only command, including the same commands under a pseudo-terminal wrapper. Run `openmoat policy upgrade` to add the group to an existing policy ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
