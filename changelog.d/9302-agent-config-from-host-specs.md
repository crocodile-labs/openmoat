### Security
- `openmoat run` now denies commands writing every agent's configuration in the project, in every tier: Cline's workspace hooks (`.cline/hooks/`, `.clinerules/hooks/`), Gemini CLI's project policy files, custom commands and subagents (`.gemini/policies/`, `.gemini/commands/`, `.gemini/agents/`), Claude Code's subagents, skills and slash commands, GitHub Copilot CLI's custom agents (`.github/agents/`), and OpenCode's commands and `.opencode/package.json` were held for review only when the agent wrote them with its own tools, and a command it ran could write them. Each agent's files that run later now come from its spec, and the default policy's agent lines in `runs-later` and `project-fs` are generated from it; the set of files the policy reviews is unchanged (ADR-091) ([#9302](https://github.com/crocodile-labs/openmoat/pull/9302)).
