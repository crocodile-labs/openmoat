### Security
- `openmoat run` decides relayed hook calls only for its own agent and its own sessions: a call for another host, a session the audit log already holds from outside the run (unless the agent's own session start resumes it), a `run-…` session, or a 65th session gets a deny and a `run-guard-host` or `run-guard-session` row. A relayed call no longer leaves an MCP ticket. Before, any code in the run's sandbox (a script, a test runner) could use `MOAT_GUARD_TOKEN` to write rows under any host and session and to leave tickets an `openmoat mcp proxy` outside the run would take (ADR-069).
