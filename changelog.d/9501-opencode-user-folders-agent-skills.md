### Security
- Writes to OpenCode's own agents, modes and skills in `~/.config/opencode` (`agents/`, `agent/`, `modes/`, `mode/`, `skills/`, `skill/`, and those folders and the command and tool folders themselves) now need review, and a project's `.opencode/modes/`, `.opencode/mode/` and `.opencode/skill/` join its agent configuration, which `openmoat run` keeps commands from writing ([#9501](https://github.com/crocodile-labs/openmoat/pull/9501)).
- The shared Agent Skills folder `.agents/skills/`, which Codex, Cursor, GitHub Copilot CLI, pi, Gemini CLI, OpenCode, goose and Antigravity CLI load into later sessions, is now agent configuration in every session, not only after untrusted content: an agent's write there, or to the `.agents` and `.agents/skills` folders, needs review, and `openmoat run` keeps commands from writing it ([#9501](https://github.com/crocodile-labs/openmoat/pull/9501)).
