### Fixed
- A loop over words the command shows no longer needs review when its variable is trimmed into a `sed` or `awk` script (`for x in a.md:21 b.md:17; do n=${x#*:}; sed -n ${n}p ${x%%:*}; done`): a prefix or suffix removed from a known value (`${x#pat}`, `${x##pat}`, `${x%pat}`, `${x%%pat}`) is known too. A variable set inside such a loop now holds every value the loop gives it, not only the last, so `for x in ~/.ssh/id_rsa README; do y=$x; cat $y; done` is denied; and a `sed` script the shell expands an unknown value into (`read n; sed -n "$n" f`) is held for review ([#831](https://github.com/crocodile-labs/openmoat/pull/831)).
