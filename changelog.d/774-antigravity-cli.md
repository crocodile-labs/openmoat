### Added
- Antigravity CLI (`agy`) support: `openmoat init` writes a named `openmoat` entry with one `PreToolUse` hook to `~/.gemini/config/hooks.json`, shared with the Antigravity app and IDE. Every documented tool is mapped by what it does; a review is sent as `force_ask` so a saved "Always Allow" cannot answer it, and a saved `toolPermission: always-proceed` turns one into a deny. The default policy keeps the agent from changing its hook, settings, MCP and plugin files and from reading its MCP OAuth tokens. Built from the official documentation (no version stated) and not yet checked against a running `agy`: what the host does when the hook fails is not documented, so treat a failing hook as letting the call run ([#774](https://github.com/crocodile-labs/openmoat/pull/774)).
