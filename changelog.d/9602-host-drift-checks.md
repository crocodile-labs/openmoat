### Security
- A file you name with `@` in a Claude Code prompt is now read through OpenMoat's hook: `openmoat init` sets `CLAUDE_CODE_DISABLE_FILE_MENTIONS=1` in the `env` of your Claude Code `settings.json`, so Claude Code (2.1.299 or later) reads the file with its file tools instead of inserting it with no tool call. A secret named that way is denied like any other read of it. An install without the variable is reported as needing `openmoat init`; `openmoat uninstall` takes it out ([#9602](https://github.com/crocodile-labs/openmoat/pull/9602)).
- Grok Build and the Devin CLI run the hooks in Claude Code's settings files with their own tool names, which OpenMoat's Claude Code hook used to leave unchecked. Such a call is now checked for every path, URL and command its arguments name, and a call that needs review is denied with how to approve it, since neither agent asks the person (ADR-095) ([#9602](https://github.com/crocodile-labs/openmoat/pull/9602)).

### Changed
- The pages for Codex, Gemini CLI, GitHub Copilot CLI, goose, Hermes Agent, pi and OpenCode record their changelogs as reviewed to the latest release, separately from the version their hook format was checked against. Gemini CLI 0.68.0 still reads `"ask"`, which OpenMoat sends for a review; OpenCode 2.3.0 still rejects a call whose plugin throws; Codex 0.167 runs the hook before its Guardian review; OpenClaw's trusted tool policies cannot undo OpenMoat's first-and-last decision; from Hermes Agent v0.23.0 a browser call is checked as an unknown tool ([#9602](https://github.com/crocodile-labs/openmoat/pull/9602)).
