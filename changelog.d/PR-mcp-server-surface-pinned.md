### Security
- `openmoat mcp proxy` now pins a server's `initialize` instructions and server information, and each entry of its prompt, resource and resource-template listings, with its tools: new or changed instructions are taken out of the answer the agent gets, a new or changed prompt or resource is left out of its listing (and a held prompt is not filled in), until `openmoat mcp accept` shows what changed; a new version number alone asks nothing, and a server accepted before this release is not asked about again. Accepted instructions are kept as untrusted content of each session that calls the server (`injected-input`, and the session counts as having read untrusted content) (ADR-069) ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
