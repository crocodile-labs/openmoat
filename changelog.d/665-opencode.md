### Added
- OpenCode 1 (`opencode-ai`) is a supported agent, host `opencode`, hook only: `openmoat init` writes OpenMoat's plugin to `~/.config/opencode/plugins/openmoat.js` (or `$XDG_CONFIG_HOME/opencode`), which checks every tool call through `tool.execute.before` and blocks the call when `openmoat` is missing, fails or takes over 45 s. OpenCode 1 cannot ask, so an `ask` is a deny that says how to approve the call. The default policy denies the agent changing the plugin and the files that load plugins, starting OpenCode with `--pure` or `OPENCODE_PURE`, `opencode upgrade --major` and `opencode plugin --global`, and asks before it writes other plugins, custom tools, commands or a project's `opencode.json`. OpenCode 2 (`@opencode/cli`) is not supported yet: `openmoat init` does not set it up, and `openmoat status` and `openmoat doctor` report it as not protected ([#665](https://github.com/crocodile-labs/openmoat/pull/665)).
