### Security
- `openmoat guard` sends a hook call to `openmoat run` only from inside the run's sandbox: its own lock refused by Seatbelt on macOS, or under the seccomp filter `openmoat run` applies on Linux. A hook outside any run whose environment sets `MOAT_GUARD_SOCKET` and `MOAT_GUARD_TOKEN` is decided where it is, and a `run-guard-outside` row records that the variables were there; before, a listener at that address that repeated the nonce answered every call (ADR-070).
