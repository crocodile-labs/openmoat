### Added
- Each week CI installs the latest release of every supported agent, sets it up with `openmoat init` and checks `openmoat status` and `openmoat doctor`; where the agent runs without an account it is started against a local fake model API and must have its read of `~/.ssh/id_rsa` denied by OpenMoat. A failure opens an issue naming the agent and its version. Separately, the published release is installed each week and after every release with Homebrew, the shell installer and `cargo install`, the README quick start is run as written, and `openmoat uninstall` must give back every file `openmoat init` changed, byte for byte ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
