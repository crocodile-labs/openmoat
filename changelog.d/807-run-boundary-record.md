### Security
- Every `openmoat run` writes one `run-boundary` audit row with the sandbox it really started with: the tier asked for and the one that started, each downgrade and why (a project top opened by `sandbox.project_top: writable` included), the network mode, the Landlock ABI as `restrict_self` reported it, whether tool commands get the relay token, and each restriction's available / configured / applied / tested; `openmoat run --print-boundary [--format json]` prints the same without starting the agent. On Linux the run reads the agent's `/proc/<pid>/status` right after it starts and stops it, with every process it started, when `NoNewPrivs: 1`, `Seccomp: 2` with this run's filters, or an enforced Landlock ruleset is missing, or when the row cannot be written, inside bubblewrap too. The `run-landlock-abi` row is replaced by this one ([#807](https://github.com/crocodile-labs/openmoat/pull/807)).
