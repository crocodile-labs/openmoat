### Added
- Hermes Agent is a supported agent (`openmoat init --hosts hermes`, hook only): one `pre_tool_call` hook with `fail_closed: true` in its `config.yaml`, edited as text so your comments stay, and its command approved in `shell-hooks-allowlist.json`, without which Hermes's gateway, cron and ACP sessions skip it; `openmoat status` and `openmoat doctor` report a hook the allowlist does not approve. An ask is Hermes's own approval prompt, and a deny you approve with `openmoat allow --last` where Hermes would approve it unseen (YOLO mode, `approvals.mode: off`). The lock pins both files, the MCP servers in `mcp_servers` one by one, and `kernel-self` protects Hermes's configuration, allowlist, `.env`, plugins and hooks and denies `HERMES_SAFE_MODE` ([#665](https://github.com/crocodile-labs/openmoat/pull/665)).
