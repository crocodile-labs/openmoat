### Security
- Every OS sandbox now denies the agents' login and key files (`agent-credentials`) to the commands an agent runs, so a test, package script or downloaded binary can no longer read another agent's token, or the agent's own under Claude Code's, Codex's and Cursor's sandboxes, which confine only those commands; the agents still sign in. `openmoat run`, which holds the agent itself, keeps the login of the agent it starts readable (`run.own-login`) and denies the others'. `openmoat sandbox show` lists both; `hook_only: true` on the group restores the old behaviour, and `docs/BROKER_LOGINS.md` keeps an API key out of `openmoat run` (ADR-054, [#735](https://github.com/crocodile-labs/openmoat/pull/735)).
