### Added
- Remote MCP servers through the gateway (preview, ADR-127): `openmoat mcp login <server> --url <url>` pins a Streamable HTTP server's URL and keeps its token owner-only in OpenMoat's state directory (`kernel-self` denies agents the command and reading `mcp-remote/`), and `openmoat mcp remote --server <server> --url <url>`, started by the agent in place of the remote entry, runs the same relay as stdio servers (pinned tools and identity, a hook decision per call, result checks) and adds the token itself, so the agent never holds it. Every address the server's name resolves to is checked as the egress proxy checks it (local and private addresses only when an allow rule names them, link-local and metadata never), no redirect is followed, and the server's sign-in metadata (RFC 9728) is read only over `https` and only named; signing in through OAuth is not built yet ([#862](https://github.com/crocodile-labs/openmoat/pull/862)).
