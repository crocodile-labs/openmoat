### Added
- The Cline CLI (`cline`, npm `@cline/cli`) is supported: `openmoat init --hosts cline` writes OpenMoat's `PreToolUse` hook script to `~/.cline/hooks` (`CLINE_DIR` moves it), which Cline runs before every tool call. `run_commands` (every command shape Cline accepts), `read_files`, `editor`, `apply_patch`, `search_codebase`, `fetch_web_content` and MCP tools are checked, and any other tool by what its arguments name; the servers in Cline's `cline_mcp_settings.json` are pinned. Cline runs a call whose hook fails, so the script itself blocks the call when `openmoat` is missing or does not answer. Cline's hooks cannot ask, so an ask is a deny you approve with `openmoat allow --last`. The default policy's `kernel-self` now protects Cline's hook and plugin directories (and `~/Documents/Cline/Hooks`), `agent-credentials` its stored provider keys and connector credentials, and session taint its `.cline` and `.clinerules` files. The Cline VS Code extension, `--yolo` runs and native Windows are not covered ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
