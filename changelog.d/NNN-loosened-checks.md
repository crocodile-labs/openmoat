### Changed
- An `awk` program whose `|` is regex alternation or whose `>` sits inside a regex or a string (`awk '/^## |^# /{print}' f`, `awk '/>>>>>>> /{p=0}' f`, `awk '{print $1 " -> " $2}' f`) is read-only and allowed by `text-tools`; a pipe, a redirection, `system`, `getline`, `ENVIRON`, `close(`, `fflush(`, a program file and a program the shell expands a variable into (`awk "$prog"`) still ask ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- `perl -pi -e 's/a/b/g' FILE…` (also `-0pi`, `-pi.bak`, `-i -pe`, `-ni`, `-0777 -pi`, any delimiter or bracket pair, several substitutions) is an edit of the named files, decided by the path rules as `sed -i` is: a project file allows, `~/.zshrc` is `shell-rc`, a hook under `.git` asks. The `e` flag, interpolated code or variables, anything beside the substitutions, a `-M` module and a program in a shell variable are decided as any other inline program, and `perl -pe` without `-i` is unchanged ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- `git -c KEY=VALUE` with a key that never names a program (`user.name`, `user.email`, `commit.gpgsign=false`, `init.defaultBranch`, `advice.*`, `color.*`, `i18n.*`, `core.autocrlf`, `core.safecrlf`, `core.quotepath`, `pull.rebase`, `pull.ff`, `push.default`, `push.autoSetupRemote`, `fetch.prune`, `rebase.autostash`, `rebase.autosquash`, `merge.conflictstyle`, `diff.renames`, `log.date`, `status.short`, `gc.auto`) is no longer `git-internals`; every other key (`core.hooksPath`, `alias.*`, `core.editor`, `credential.helper`, `include.path`, `user.signingkey`, `commit.gpgsign=true`, …) still asks, and `git init --template=DIR` with a directory now asks too while an empty `--template=` does not ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- `env-poison` no longer sees an assignment whose value changes nothing: `GIT_EDITOR`, `GIT_SEQUENCE_EDITOR`, `EDITOR` or `VISUAL` set to `true`, `:` or `cat`, and `PATH` kept as `$PATH` or set to system directories only (`/usr/bin:/bin`, `/usr/bin:/bin:/usr/sbin:/sbin`, `/usr/local/bin:/usr/bin:/bin`), prefixed, exported or given to `env -i`. `EDITOR` and `VISUAL` set to anything else (`EDITOR=/tmp/x`) are now denied like `GIT_EDITOR`, and a `PATH` that adds any other directory stays denied ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- `git branch -D NAME` and `git branch --delete --force NAME` ask (new group `destructive-recoverable`: the reflog holds the commits for weeks) instead of being denied by `destructive`, which keeps `git push --force`, `git push --delete`, `git reset --hard`, `rm -rf ~` and the rest; run `openmoat policy upgrade` to add the group to an existing policy ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
