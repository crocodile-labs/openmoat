### Added
- `openmoat policy check-diff` checks a change before it is merged: from `--base` to `--head`, or a unified diff on stdin. Every file the change adds, edits, deletes or renames is decided by the policy's own rules as a write from untrusted content, so CI workflows, git hooks, build and package files and agent settings are reported for `review` and what the policy denies an agent (`.claude/settings.json`, `.env`, `.moat/`) as `deny`; added lines holding a known token format, symbolic links, submodules and paths outside the repository are reported too. Paths are compared without letter case and in their Windows spelling. With `--base` the policy files (`--policy` and the repository's `.moat/policy.yaml`) are read as the base revision has them, so a change cannot loosen its own check, and a change to one is reported. Exit 0 clean, 2 deny, 3 review; `--format text`, `json` or `github` (workflow annotations, the default under GitHub Actions). A composite `action.yml` at the repository root runs it on pull requests with a pinned release whose sha256 and build attestation it checks (`docs/MERGE_CHECK.md`, ADR-050) ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
