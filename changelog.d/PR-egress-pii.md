### Security
- A payment card number sent off the machine is denied (`card-egress`, ADR-052): 13 to 19 digits with a card brand's prefix and length that pass the Luhn check, contiguous or in printed groups, in a URL a fetch, network or MCP tool opens or names, a web search query, or the arguments of a command that connects to a host (`curl -d`, `-H`, `--json`, a query, a pipe into `curl`), allowed hosts included. Sends to this machine (`localhost`, `127.0.0.0/8`, `::1`) and the test numbers payment processors publish are left out; file contents and encoded data are not read. Ten or more distinct mail addresses in one send become the atom `@pii-egress emails <host>`, which no default rule names, so they change no decision unless a policy adds a rule. A policy without a `@pii-egress` rule decides as before; `openmoat policy upgrade` adds `card-egress` ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
