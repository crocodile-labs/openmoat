### Security
- Codex and Cursor no longer take the tool's working directory, which the model chooses, as the project: a command run from outside the session's project (Codex's `workdir`, a Cursor `cwd` outside every workspace root) is decided from the session's directory as running there, so a write from `~/Library/LaunchAgents` is checked as that path ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
- Codex: a command that starts a shell, REPL, editor or login with no script or command of its own (`bash`, `python3`, `node`, `sqlite3 db`, `ssh host`, …) needs review, since Codex types later input into it with `write_stdin`, which runs no hook; `bash x.sh`, `python3 x.py` and `ssh host cmd` are decided as before ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
- Codex: `read_mcp_resource` and `view_image` are hooked and checked as the resource or image they read; trust OpenMoat's hook again in Codex's `/hooks` after `openmoat init`, since its matcher changed ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
- Hermes Agent: a review's `rule_key` names the call, so Hermes's "always" approves that call again and never another one held for the same reason ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
- Hermes Agent: a relative file path is checked against the directory Hermes started in instead of always needing review; one that climbs out (`..`) and a `terminal` call that moves the session's shell outside that directory need review, and the message names the file and whether it is read or written ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
- Gemini CLI: `grep_search` and `glob` without a `dir_path`, and `read_many_files`, are checked over the working directory and the `context.includeDirectories` of the user and project settings instead of always asking ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
- Cursor: a command Cursor runs in its sandbox (`sandbox: true`) that no rule decides is allowed, as Cursor would run it, while OpenMoat's `sandbox.json` is installed; it no longer asks ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
- Cline: the payload limit counts Cline's two copies of a call's arguments once, so a file is refused at the same size as on other agents, with a message that says to write it in parts ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
- `openmoat init` says when it moves a person's own whole-file hook (Cline's `PreToolUse`) aside, and `init` and `uninstall` keep a host file's permission bits instead of making it owner-only ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
- `INSTALL.md` names goose's real hook file, `~/.agents/plugins/openmoat/hooks/hooks.json` ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
