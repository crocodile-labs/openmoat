### Added
- An SDK puts OpenMoat's decisions into your own agent product (docs/SDK.md, ADR-046): `openmoat-sdk` for Rust and `@openmoat/sdk` for JavaScript (`sdk/js`, the engine as a WebAssembly module that imports nothing; no dependencies, no network, no telemetry). Compile a policy once, then decide each tool call (shell command, file read or write, network host, fetch, web search, MCP or unknown tool) before it runs, with filesystem facts (program pins, symlinks, glob operands), session taint and repository policies; each decision carries its verdict, rule ids and reasons, and in JavaScript a frozen copy of the action decided. The SDK decides and the caller enforces: a denied call must not run, an `ask` runs only after a person approves that exact call; it is not a sandbox. Both packages decide every conformance fixture exactly as `openmoat guard` does, and carry the release's version. Examples with tests: `crates/openmoat-sdk/examples/agent_loop.rs`, `sdk/js/examples/agent-loop.js` ([#686](https://github.com/crocodile-labs/openmoat/pull/686)).
