### Added
- `openmoat init` can plant decoy keys, if you say yes at the terminal (the default is no; `--yes`, `--dry-run` and scripts never plant): fake AWS, GitHub and npm keys at backup names no program loads (`~/.aws/credentials.bak`, `~/.git-credentials.bak`, `~/.npmrc.bak`), only where the folder exists and nothing is at that name, shaped like real keys and marked `OpenMoatDecoy`; `d` shows each file first. A call that reads or changes one, or carries one of their values in a command, a URL, a file it writes, an MCP call or a request through `openmoat proxy` to any host, is denied with the new rule `canary`, and `openmoat status`, `openmoat doctor` and `openmoat report` flag it. The record of them, `~/.moat/canaries.json`, is pinned by the lock and added to `kernel-self`'s reads; `openmoat uninstall` deletes each decoy that is still as planted (ADR-106) ([#0](https://github.com/crocodile-labs/openmoat/pull/0)).
