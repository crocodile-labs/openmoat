### Security
- `openmoat policy check-diff` (and the GitHub Action) also checks what a change's added lines do, offline, each finding with a stable rule id, its level and the exact line: a dependency whose name is a near miss of a popular one (`diff-package-near-miss`), an npm install script (`diff-install-script`), a dependency or locked package from git, plain http or another host than its registry (`diff-package-source`), a lockfile hash changed or removed while the version stays (`diff-lock-integrity`, deny); in GitHub workflows, `pull_request_target` with a checkout of the pull request's code (`diff-ci-pr-target`, deny), write permissions (`diff-ci-permissions`), `uses:` without a full commit SHA (`diff-ci-unpinned`), an author's text such as an issue title expanded into a script (`diff-ci-injection`, deny) and a printed secret (`diff-ci-secret-out`, deny); `curl … | sh` (`diff-pipe-to-shell`), decoded text run as code (`diff-decode-exec`, deny), a `.pth` file with an `import` line (`diff-python-startup`, deny), a Dockerfile `ADD` of a URL without `--checksum` (`diff-docker-remote-add`), a long base64 blob in source code (`diff-encoded-blob`), a private key (`diff-private-key`, deny; review in a test fixture or marked fake), a real-looking `.env` value (`diff-env-secret`), and one finding per new host that the policy's network allow list does not name (`diff-new-host`). The policy's new `check_diff.levels` sets any of them to `deny`, `review` or `off` (docs/MERGE_CHECK.md, ADR-055) ([#736](https://github.com/crocodile-labs/openmoat/pull/736)).
