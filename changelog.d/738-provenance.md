### Added
- `openmoat provenance` shows which files of your commits an agent session wrote, from this machine's audit log, and where one recorded write made the whole change, which added lines. For each file it names the agent, the session and the time, and says whether the session had read web content, an MCP result or a file such a session wrote before writing. `--write-notes` (person-only) keeps a versioned JSON note per commit on `refs/notes/openmoat`; share them with `git push origin refs/notes/openmoat`. `--verify` checks each note's digest, audit head and cited events against the log, and attributes the commit again. `openmoat policy check-diff` and the merge check Action show the notes as review-level lines (`--provenance review|info|off`, Action input `provenance`); they never change the exit code. A missing note proves nothing (docs/PROVENANCE.md, ADR-056) ([#738](https://github.com/crocodile-labs/openmoat/pull/738)).
