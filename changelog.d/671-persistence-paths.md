### Security
- `shell-rc` also denies writes to fish's startup files (`~/.config/fish/config.fish`, `conf.d/`, `functions/`), the login and logout files (`~/.zlogin`, `~/.zlogout`, `~/.bash_login`, `~/.bash_logout`, `~/.login`), csh, tcsh, ksh and mksh startup files (`~/.cshrc`, `~/.tcshrc`, `~/.kshrc`, `~/.mkshrc`) and the drop-in folders `~/.bashrc.d/` and `~/.zshrc.d/`, which run as often as `~/.zshrc` and were deferred; the host sandboxes deny them too. Reading them is unchanged ([#671](https://github.com/crocodile-labs/openmoat/pull/671)).
- Writing into a folder on `PATH` (`~/.local/bin`, `~/bin`, `~/.cargo/bin`, `/usr/local/bin`, `/opt/homebrew/bin`) now asks (`persistence`): a file there named after `git`, `ls` or `node` runs in its place later. `install -m755 evil ~/.local/bin/git` and `ln -sf evil ~/.local/bin/git` were deferred. Installers (`pipx install`, `uv tool install`, `cargo install`, `brew install`, `npm i -g`) are commands, not writes, and are unchanged ([#671](https://github.com/crocodile-labs/openmoat/pull/671)).
- `env-dump` also denies inline Python that reaches the environment through `__import__('os')` (`python3 -c 'print(__import__("os").environ)'`, `__import__("os").__dict__`), which was deferred. An alias (`e = os.environ; print(e)`) is still not followed ([#671](https://github.com/crocodile-labs/openmoat/pull/671)).
- `kill` of the pids a command substitution naming `moat` looks up now asks like `pkill openmoat` (`stops-openmoat`): `kill -9 $(pgrep openmoat)`, `kill $(pidof moat)` and `` kill `pgrep -f openmoat` `` were deferred. `pgrep openmoat` alone and `kill $(pgrep node)` are unchanged ([#671](https://github.com/crocodile-labs/openmoat/pull/671)).
- Writing what every Python start runs now asks (`runs-later`), the allowed `pytest` included: a `.pth` file in a `site-packages` or `dist-packages` directory, and `sitecustomize.py` or `usercustomize.py` anywhere, a project's `.venv` and `src/` included. They were deferred outside the project and allowed inside it. Session taint protects them too; the host sandboxes leave them writable, since installs write them ([#671](https://github.com/crocodile-labs/openmoat/pull/671)).
