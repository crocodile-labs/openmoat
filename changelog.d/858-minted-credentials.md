### Added
- Preview: `source: mint` brokers short-lived credentials the proxy makes from one you hold and narrows to what the entry names: a GitHub App installation token for named repositories and permissions, AWS STS `AssumeRole` credentials with a session policy (15 minutes to 12 hours), and a Google Cloud service account token for named scopes; each is renewed before it ends, and a mint that would not narrow does not load. GitHub OAuth and personal access tokens such as `gh auth token`'s cannot be narrowed, so they are not minted from (ADR-118) ([#858](https://github.com/crocodile-labs/openmoat/pull/858)).
- Preview: `helper: git` and `helper: aws` hand a secret to git's credential helper and the AWS tools' `credential_process` inside `openmoat run`, which sets both up; the proxy answers only the session's own processes and, for git, only the secret's own host, and records every answer (`proxy-helper`). A value handed out this way is readable by the session's commands; LIMITS.md says what bounds it ([#858](https://github.com/crocodile-labs/openmoat/pull/858)).
