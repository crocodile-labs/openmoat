### Added
- `@openmoat/sdk` adds OpenMoat to an agent framework with one line: `@openmoat/sdk/claude-agent-sdk` (a `PreToolUse` hook), `/openai-agents` (a tool input guardrail), `/ai-sdk` (the Vercel AI SDK's `execute`), `/mastra` (`beforeToolCall`) and `/langchain` (a `wrapToolCall` middleware). A denied call does not run and the model gets OpenMoat's reason; a call that needs review does not run unless a `review` callback approves it; `defer` goes to the framework's own approval; every error blocks the call; each decision's time is recorded. The package still has no dependencies, and each adapter's types are checked against its framework's release ([#822](https://github.com/crocodile-labs/openmoat/pull/822)).
- docs/SDK.md says when a Claude Agent SDK app runs OpenMoat's hook with no code: with `settingSources` left out it loads the user settings `openmoat init` wrote, as the SDK's documentation and source show; and ADR-096 designs a Python SDK ([#822](https://github.com/crocodile-labs/openmoat/pull/822)).
