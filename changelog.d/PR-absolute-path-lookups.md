### Security
- OpenMoat no longer runs, pins or records a program found through a relative `PATH` entry (`.`, `node_modules/.bin`): the `--version` probes of `init`, `status` and `doctor` (which OpenMoat Bar runs every minute), the pinned programs `init` records, the binary path written into hooks, the agent `openmoat run` starts by name, and the `git` that `provenance` and `policy diff` run all come from the absolute entries only, so a repository with a planted `claude` or `git` cannot get it run from there (ADR-067) ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
