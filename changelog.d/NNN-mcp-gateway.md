### Security
- `openmoat mcp proxy` is now an MCP gateway (ADR-045): a call OpenMoat refuses never reaches the server, and every call it passes is tied to the agent session that made it. A `tools/call` passes only when the policy does not deny it as the server receives it (the paths and URLs its arguments name, under the name `mcp__<server>__<tool>` whatever the agent calls the tool) and when the hook decided exactly that call: the same tool and arguments, within the hour, each decision used once. The proxy's audit row (host `mcp-proxy`) carries the hook's session and call id, so the session's taint and the person's answer to an `ask` apply. A call no hook decided is refused with rule `mcp-unattributed` ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- The proxy no longer passes on bytes it did not check: every message it sends is the one it read, written again by itself, so a key given twice, a `\r` inside a line or a line separator inside a string can no longer carry a message the proxy did not check to the server, or an unfiltered tool listing to the agent. A line from the server it cannot read is dropped instead of passed on. Batches inside batches, messages that are both a request and a response, ids that are not strings or numbers, reused ids and a method spelled in another case are refused ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- A response from the server reaches the agent only when it answers a request the agent sent, so a server can no longer answer a call the proxy refused or send a tool listing nobody asked for ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- When a server says its tools changed (`notifications/tools/list_changed`), the proxy reads them again itself and holds each changed tool, even if the agent keeps its old list. Under `mcp.trust_first_sight`, a call made before the server's first listing is refused ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- `resources/read` through the proxy is decided on its URI (a `file:` URI as the file it names, an `https:` one as the host), and `prompts/get` and the server's own requests to the agent (`sampling/createMessage`, `elicitation/create`) are recorded ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- The audit database is at schema version 6: it holds the MCP calls the hook let through until the proxy uses each or it is an hour old. An older database is upgraded when OpenMoat first writes to it ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- A server wrapped with `openmoat mcp wrap` now answers only calls an agent's OpenMoat hook decided; a script or tool that used a wrapped server directly gets error -32001 (`mcp-unattributed`). `openmoat mcp unwrap <server>` takes the proxy out of its path ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
