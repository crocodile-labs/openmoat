### Changed
- **Breaking** `openmoat-core`: `Decision` has a new public field `notice` (`Option<Box<Notice>>`, never serialised; set it to `None` where you build a decision yourself, or use `Decision::new`), `RuleGroup` has the new public fields `title` and `why`, and `Notice`, `TITLE_MAX_CHARS`, `WHY_MAX_CHARS`, `Policy::own_group`, `Policy::untitled` and `lint::untitled` are new. The policy format gains the optional `title:` and `why:` per rule; an older OpenMoat rejects a policy that uses them. `openmoat-hosts` adds `rule_page` and `RULE_PAGE`, and `reason_line` renders a decision's notice as the block message; `openmoat-audit` adds `Store::after`, `Store::between` and `Store::latest_held` ([#751](https://github.com/crocodile-labs/openmoat/pull/751)).
