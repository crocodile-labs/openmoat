### Added
- Qwen Code, in preview: `openmoat init` adds a `PreToolUse` hook named `openmoat` to `~/.qwen/settings.json` (or `QWEN_HOME`) for Qwen Code 0.13.0 and later, and `openmoat guard --host qwen-code` reads its Claude Code-shaped payload with Qwen Code's own tool names, answering a review as `ask`. Built from Qwen Code's documentation and source, not yet run against a real `qwen`; a hook that fails or times out lets the call run, as Qwen Code has no fail-closed setting. The default policy protects `~/.qwen`, a project's `.qwen` and `QWEN.md`, and the weekly job installs the latest release ([#9721](https://github.com/crocodile-labs/openmoat/pull/9721)).
