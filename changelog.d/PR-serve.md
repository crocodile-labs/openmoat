### Added
- `openmoat serve` shows what `openmoat status`, `show`, `report` and `why` show in a browser on this machine, and the same JSON their `--format json` prints under `/api/`. It listens on 127.0.0.1 or `[::1]` only and refuses any other address, prints a link with a token made for the run once, and answers only requests that carry it, name the server as `127.0.0.1`, `localhost` or `[::1]` and come from no other site; it is read-only (`GET` only, no path changes anything), sets no cookie and no CORS header, and its pages run no script under a strict Content Security Policy. Like `openmoat allow`, it refuses to start when an agent started it, and the default policy denies `openmoat serve` to agents (`kernel-self`) ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
