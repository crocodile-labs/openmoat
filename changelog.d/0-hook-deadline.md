### Security
- A slow hook no longer lets a call run in agents that run a call whose hook timed out (Codex, GitHub Copilot CLI, Gemini CLI, Qwen Code, Crush, Cline CLI, Antigravity CLI): `openmoat guard` answers deny on its own at a deadline per agent, 30 s or the agent's shortest hook time limit less 5 s (25 s for Hermes Agent), from a watchdog that starts before the guard reads a file and writes the deny once, in the form of the call's event, whatever the decision is stuck on; the audit log records it as `hook-deadline` where it can still be written, and `docs/LIMITS.md` says what remains (a guard stopped, or killed with the hook command, before it answers) (ADR-120) ([#0](https://github.com/crocodile-labs/openmoat/pull/0)).
