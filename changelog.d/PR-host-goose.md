### Added
- goose support (#263): `openmoat init` writes OpenMoat's goose plugin, `~/.agents/plugins/openmoat/hooks/hooks.json`, with one `PreToolUse` entry for every tool that sets `on_failure: block`, so a hook that cannot start, crashes or times out blocks the call. `shell`, `write`, `edit`, `tree`, `analyze`, `read_image` and extension tools are checked; goose cannot ask, so an ask is a block approved with `openmoat allow --last`; Code Mode's `execute_javascript` asks, since its tool calls skip the hook. MCP extensions in `config.yaml` are pinned, `disabledPlugins` naming `openmoat` reports goose as not protected, and the default policy keeps the agent from changing goose's configuration and any `.agents/plugins` directory ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
