### Security
- Injected input now covers PowerShell commands (Gemini CLI's shell on Windows, the PowerShell tools of Claude Code and the Cline CLI). OpenMoat does not parse them, so it reads their text for the hosts and paths they name: a host or a path outside the project that untrusted output named makes the command need review (`injected-input`), and a PowerShell command that reaches a host the policy does not allow has its output kept like a `curl` of it. A host or path built at run time is not seen. Gemini CLI's hook-failure facts now say what its source does: a hook that cannot start (`openmoat` missing) blocks the call, a hook that crashes or exits 1 lets it run; `docs/LIMITS.md`, `docs/PROTECTION.md` and `openmoat status --format json` (new `cannot_start`) agree with `docs/INSTALL.md`. `openmoat status` no longer says goose's `builtin` and `platform` extensions run nothing on this machine: they run inside goose's own process ([#9204](https://github.com/crocodile-labs/openmoat/pull/9204)).
