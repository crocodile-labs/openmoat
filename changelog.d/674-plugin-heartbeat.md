### Security
- OpenClaw now runs the parameters OpenMoat decided on (ADR-041). OpenClaw shows each `before_tool_call` handler the call as it came and runs the `params` of the last one that returns some, so another plugin could turn a checked `git status` into `cat ~/.ssh/id_rsa` and that ran. OpenMoat's plugin now decides at the highest priority and returns the parameters it checked at the lowest, which undoes such a change; a plugin that changes a call and asks for approval in the same answer keeps its change once a person approves it, as THREAT_MODEL §5 says ([#674](https://github.com/crocodile-labs/openmoat/pull/674)).
- A plugin its agent did not load no longer looks protected (ADR-042). OpenClaw, pi and OpenCode start without a plugin that fails to load and then run every call unchecked. OpenMoat's plugins now run `openmoat guard --heartbeat --host <id>` as they load, and `openmoat status` and `openmoat doctor` say "plugin not loaded yet" (a note) until the plugin has reported or sent a call since `openmoat init` wrote it or the agent was updated; when pi wrote a session since without either, they warn and report pi as not protected. `openmoat status --format json` lists it under `plugins`. The default policy denies an agent running `openmoat guard --heartbeat` itself (`kernel-self`), so one agent cannot report another's plugin as loaded ([#674](https://github.com/crocodile-labs/openmoat/pull/674)).
- An entry of OpenMoat's without the agent's fail-closed key (`fail_closed: true` for Hermes Agent, `failClosed: true` for Cursor) is reported as not protected, with the reason, instead of "out of date": the agent would run a call whose hook failed. `openmoat init` puts the key back ([#674](https://github.com/crocodile-labs/openmoat/pull/674)).
- Hermes Agent's limits are documented from its source: its `plugins.hook_callback_timeout` (30 s by default) blocks a call whose hook has not answered, before the entry's own 60 s and together with the guard's own 30 s, so `openmoat init` leaves it alone; and Hermes runs a call unchecked when its own hook dispatcher raises an error ([#674](https://github.com/crocodile-labs/openmoat/pull/674)).
- The OpenClaw, pi and OpenCode plugins are type-checked (`// @ts-check`, strict, `scripts/ci/check-js.sh`) and each runs under Node against a stand-in for its host and for the guard in the tests: every failure of the guard blocks, a deny, ask, allow and no answer reach the agent as they must, and the OpenClaw rewrite is undone ([#674](https://github.com/crocodile-labs/openmoat/pull/674)).
