### Changed
- **Migration:** `openmoat run` on Linux starts the Isolated tier (bubblewrap) by default where bubblewrap works, so commands the agent starts can no longer read `.env` or write `.git/hooks` and `.moat` in the project. The agent sees only the project, the read roots, its executable, the `--write` paths and an empty temp directory; an agent whose runtime lives elsewhere in the home can need that directory in `sandbox.read_roots`. Where bubblewrap is missing or blocked it says why on every start, records `run-isolation-unavailable` in the audit log and starts the Lightweight tier as before. `--no-isolate` starts the Lightweight tier on purpose and records `run-no-isolate`; `openmoat doctor` says which tier applies. Under `require.run: full-boundary` the Isolated tier is required on Linux and `--no-isolate` is refused (ADR-080) ([#789](https://github.com/crocodile-labs/openmoat/pull/789)).
