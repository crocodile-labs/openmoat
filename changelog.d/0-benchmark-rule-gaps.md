### Security
- The default policy closes the gaps two outside benchmarks (RedCode-Exec, agent-egress-bench) found, adding denies and reviews only (ADR-112): the system's password hashes and SSH host private keys are secret paths (`/etc/shadow`, `/etc/gshadow`, `/etc/security/opasswd`, `/etc/ssh/ssh_host_*_key`); writes, deletes and moves in the operating system's folders need review (`system-files`: `/etc`, `/usr` but not `/usr/local`, `/bin`, `/sbin`, `/lib*`, `/boot`, `/System`), and inline code that deletes a file (`os.remove`, `Path.unlink`, `fs.rmSync`) counts as a write there and everywhere; `persistence` covers the system's cron and systemd folders, `/Library/LaunchDaemons` and `/Library/LaunchAgents`, `systemctl enable` and `launchctl load`; a fetch tool reaches no address `curl` cannot (an IP address in any spelling is `net`, plain `localhost` still defers) and a URL inside a URL (`?target=http://169.254.169.254/`) is checked for fetch tools and `curl` alike; `token-egress` knows GitLab's other token prefixes, an AWS secret key given by name and PEM private keys; a JWT or a database URL with a password sent off the machine needs review (`credential-egress`); and stopping a system process (`pkill sshd`, `pkill -u root`, `kill -9 1`, `kill $(pgrep sshd)`) needs review (`stops-system`) ([#0](https://github.com/crocodile-labs/openmoat/pull/0)).
