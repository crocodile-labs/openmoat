### Security
- Claude Code in VS Code and JetBrains: `openmoat init` now finds the Claude Code the VS Code extension bundles (and the same extension in VS Code Insiders, VS Code Server, Cursor, Windsurf and VSCodium) from the editor's `extensions.json`, so a person who uses only the extension gets `onFailure: "block"` and a hook that fails blocks the call; an older copy beside it leaves the key out. `openmoat status` and `openmoat doctor` list each bundled copy, warn about one too old, and warn about Claude Code before 2.1.310 on Windows, where a hook's block could still let a call through without Git for Windows or Git Bash (ADR-060, [#752](https://github.com/crocodile-labs/openmoat/pull/752)).
- The editor tools Claude Code uses in VS Code and JetBrains are decided by what they do: `mcp__ide__getDiagnostics` and `mcp__claude-vscode__getDiagnostics` read the file their `uri` names, so a secret's diagnostics are denied like a `Read` of it (and a project file's are no longer refused as a network call), and `mcp__ide__executeCode`, which runs Python in the notebook's kernel, needs review (ADR-060, [#752](https://github.com/crocodile-labs/openmoat/pull/752)).
- `runs-later` now holds for review an agent's writes to the editors' project configuration, which the editor runs: all of `.vscode/` (tasks, launch configurations, MCP servers, settings that name a program; before, only `tasks.json`), `*.code-workspace`, all of `.idea/` and JetBrains' shared `*.run.xml` run configurations, and the `.vscode` and `.idea` folders themselves. Reading them stays allowed. Existing policies get it with `openmoat policy upgrade` (ADR-060, [#752](https://github.com/crocodile-labs/openmoat/pull/752)).
- Cursor runs Claude Code's hooks too, with its own input: OpenMoat now reads such a call as Cursor's `preToolUse` (a `Grep` naming a secret in `file_path` is denied, not read as a search of the project) and answers a `review` as a deny, since Cursor runs a `preToolUse` call answered `ask` (ADR-060, [#752](https://github.com/crocodile-labs/openmoat/pull/752)).
- Cursor's Tab (inline completion) reads are checked: `openmoat init` installs `beforeTabFileRead`, which refuses Tab reading a secret and lets every other file through; run `openmoat init` to add it (ADR-060, [#752](https://github.com/crocodile-labs/openmoat/pull/752)).
