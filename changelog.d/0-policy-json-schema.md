### Added
- JSON Schemas for policy schema version 1, so an editor can complete keys and flag a misspelt one as you type: `crates/openmoat-core/policies/policy-v1.schema.json` for your policy and `repo-policy-v1.schema.json` for repository policies and packs, with the old `ask` marked deprecated. Point the YAML language server at one with a `# yaml-language-server: $schema=…` first line (added through `openmoat edit`, since the installed policy is pinned) or VS Code's `yaml.schemas`; `openmoat policy lint` stays the check that counts. A test holds both schemas to the policy model, the default policy, the bundled pack and the examples in docs/POLICY.md (docs/POLICY.md §1.1, ADR-103) ([#0](https://github.com/crocodile-labs/openmoat/pull/0)).
