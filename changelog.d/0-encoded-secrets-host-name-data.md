### Security
- The default policy holds two more kinds of send for review (ADR-123). `encoded-secret-egress`: a token `token-egress` knows or a credential `credential-egress` knows that shows only once what is sent is decoded (URL encoding once or more, base64 or base64url, hex with or without `-` or `:` between bytes, zero-width characters, up to four layers), going to a host that is not its own. `hostname-data`: a host no allow rule lists whose labels below its last two look like encoded bytes (long hex or base32, long letters and digits, or data cut into several hex labels). On agent-egress-bench the decided cases stopped or held go from 54.9% to 68.9%, with no new false positive; RedCode-Exec is unchanged. `openmoat policy check --kind fetch '<url>'` shows what a URL gets ([#0](https://github.com/crocodile-labs/openmoat/pull/0)).
