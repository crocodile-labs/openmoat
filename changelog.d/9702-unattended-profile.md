### Added
- `unattended: review` in your own policy holds a call OpenMoat would leave to the agent (`defer`) for review when the agent runs in a mode that asks no one, as far as its hook can see: Claude Code's `bypassPermissions` and `auto` permission modes, pi without a screen, Hermes Agent in YOLO mode or with approvals off, and Antigravity CLI with `toolPermission: always-proceed`. The agent receives it as a deny that says how to approve it (`openmoat allow --last`, or the approvals channel). The default stays `defer`, so nothing changes until you set it; a repository policy or a pack cannot set it (POLICY.md §5.4, ADR-100).
- `openmoat mcp accept` (and `openmoat doctor --accept`) asks whether to run a server it accepts as new through OpenMoat, as `openmoat init` asks about the servers it finds; Enter is yes, and a no is remembered (ADR-100).
