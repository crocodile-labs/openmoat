### Added
- `openmoat allow --site`, `--dir` and `--always` take `--for <duration>` (`30m`, `2h`, `3d`, `1w`, at most 366 days): the rule ends on its own, and from then on the call gets the policy's own decision again. Without `--for` a rule lasts until removed, as before. An end that cannot be read, or a clock set back to before the rule was given, counts as ended; granting the same site, directory or command again replaces its end. `openmoat allowed` shows when each rule ends and marks ended ones `EXPIRED` (`--format json`: `expires`), `openmoat status` and `openmoat doctor` name rules that ended or end within a day, and `openmoat allow --prune` removes the ended ones. `approved.yaml` holding an end is written as `version: 2`, which earlier releases refuse rather than read as permanent ([#769](https://github.com/crocodile-labs/openmoat/pull/769)).
- `--since` (`report`, `show`, `audit`, `replay`) also reads minutes and seconds (`30m`) ([#769](https://github.com/crocodile-labs/openmoat/pull/769)).
