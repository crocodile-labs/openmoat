### Changed
- The verdict `ask` is now called `review`, everywhere OpenMoat shows or stores it: the policy's `review:` rule list and `review` default, `openmoat status`, `doctor`, `show`, `report`, `audit` and MoatBench output (`reviewed` counts, `top reviews`, `❓ review`), `--format json` (`"verdict": "review"`, and the keys `reviewed` and `top_reviews` where they said `asked` and `top_asks`), the reason line (`moat: review [rule]`), the SDKs and the docs. Nothing else changes: the same calls need a person's approval, exit code 3 still means an unresolved review, and every agent still receives its own protocol's word (`"ask"`). Upgrading: a policy that says `ask:` or `ask` keeps working as before and `openmoat policy lint` warns about it; run `openmoat policy upgrade`, which shows the rename in its diff and asks before writing. A policy with both `ask:` and `review:` is refused, with a message saying which rules to move. Audit rows written before keep `ask` (the hash chain covers them) and read as `review`; the audit database moves to schema version 8, which an older OpenMoat refuses to open ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
