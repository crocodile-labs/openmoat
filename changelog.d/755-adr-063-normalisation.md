### Security
- Injected input (ADR-057) is linked beyond exact matches where the rewrite is the same request (ADR-063 §4): a host in other case or with a trailing dot, an IPv4 address in any numeric form the URL Standard reads (`3405803783` is `203.0.113.7`), an uncompressed IPv6 address, and a subdomain of a host a URL named (`collect.evil.example` after `https://evil.example/…`) unless the policy allows the parent. A planted command run through `sudo`, `env`, `nohup` or `sh -c`, or after `VAR=value`, is linked as before; `rm -r -f x` is still not `rm -rf x`. URLs with a bracketed IPv6 host are now kept too ([#755](https://github.com/crocodile-labs/openmoat/pull/755)).
