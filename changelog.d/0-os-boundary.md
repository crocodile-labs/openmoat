### Security
- On Linux 7.2 and later (Landlock ABI 10), `openmoat run` also refuses every UDP bind, connect and send through Landlock, beside the seccomp filter's refusal of UDP sockets, so no datagram (DNS to any resolver) leaves the sandbox. Built with `landlock` 0.4.8. ([#0](https://github.com/crocodile-labs/openmoat/pull/0))
- A protection score for `openmoat run`: the kernel features the platform's sandbox can use, weighted to 100, with each missing one named and what brings it. `openmoat doctor` prints it for each tier this system can start and for the hook alone (0), and `openmoat run --print-boundary` and the run's boundary record carry it (`score`). ([#0](https://github.com/crocodile-labs/openmoat/pull/0))
- `sandbox.strict: true` (your own policy only): `openmoat run` starts only with its whole protection score, refusing before anything starts and stopping the agent when the check after the start cannot confirm a feature. On Linux that is the Isolated tier on Landlock ABI 10 (Linux 7.2) or later. ([#0](https://github.com/crocodile-labs/openmoat/pull/0))
- Qwen Code and Crush get an `openmoat run` command in `openmoat status` and `doctor`, and the sandboxed-start question of `openmoat init`. `openmoat status` lists each hook-only agent that `openmoat run` can confine here and that has no sandboxed-start shim under `Needs your attention`, with the one command that confines it; `openmoat init` names each such agent before it asks about sandboxed start. ([#0](https://github.com/crocodile-labs/openmoat/pull/0))
- Tests for the egress bypasses other agent sandboxes document: UDP and DNS from inside `openmoat run`, a request to the proxy's port without the session's credential, a raw address, a `Host` header that fronts another host, and an empty network allowlist, which reaches no host at every layer. ([#0](https://github.com/crocodile-labs/openmoat/pull/0))
