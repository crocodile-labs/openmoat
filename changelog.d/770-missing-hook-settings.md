### Security
- `openmoat run` on Linux keeps commands from creating an agent's hook settings the project lacks (`.claude/settings.local.json`, `.gemini/settings.json`, `.github/copilot/settings.local.json`, `.codex/hooks.json`, `.cursor/hooks.json`, …), with which the next session would run without OpenMoat's hook: in the network namespace and under `--isolate` each is a read-only `{}` for the session, its folders pinned, removed when the agent exits; without a namespace `openmoat run` names each that appeared when the agent exits ([#770](https://github.com/crocodile-labs/openmoat/pull/770)).
