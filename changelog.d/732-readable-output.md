### Changed
- `openmoat doctor`, `openmoat status` and `openmoat init` print one layout: what needs you first, each with its fix after `→`, one line per agent, then OpenMoat's own state, with the same marks everywhere (`✔ ! ✗ · –`), paths as `~/…`, and colour only on a terminal without `NO_COLOR`. Each check with its paths, each agent's known gaps, the hook entries `init` writes and its backups are shown with `--verbose` (`openmoat init --verbose` is new). `--format json` output and exit codes are unchanged ([#732](https://github.com/crocodile-labs/openmoat/pull/732)).
- `openmoat init` no longer asks about an agent whose files already have everything (a yes would change nothing), and ends with the agents protected and only the steps this run leaves to you, such as trusting the changed hook in Codex ([#732](https://github.com/crocodile-labs/openmoat/pull/732)).
- `openmoat policy upgrade` groups what the new default changes (new protections, fewer interruptions, the `ask` rename, comment updates counted) instead of printing the whole diff; `d` at the question, which stays `[y/N/d]` with no as the default, or the new `--diff` shows the diff. After applying it writes the agents' sandboxes as `openmoat sandbox sync` does, after the same checks ([#732](https://github.com/crocodile-labs/openmoat/pull/732)).
