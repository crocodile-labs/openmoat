### Security
- `openmoat mcp proxy` now checks its own command line against the MCP server definitions a person accepted (the pin `openmoat mcp accept` writes) before it starts anything: a new or changed wrapped server never runs its command; the agent gets an error naming `openmoat mcp accept <server>`, and the refusal is recorded (rule `mcp-server-changed`, host `mcp-proxy`). A drifted lock or an unreadable policy starts no wrapped server ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
- `openmoat status` and `openmoat doctor` warn about MCP servers that start outside OpenMoat: stdio servers that are not wrapped, wrapped ones without the sandbox, and project servers Claude Code starts without asking (`enableAllProjectMcpServers`, `enabledMcpjsonServers`) ([#PR](https://github.com/crocodile-labs/openmoat/pull/PR)).
