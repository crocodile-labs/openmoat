### Security
- `openmoat init` writes the state directory into every hook it installs (`guard --host <id> --home <dir>`, pinned by the lock with the hook file), and `openmoat guard` decides with that directory whatever the agent's environment says: a `MOAT_HOME` in the hook's environment that names another directory makes it deny the call. Before, an agent that built its hooks' environment from a file or setting OpenMoat does not guard could point the guard at another policy and lock. Hooks written by earlier releases still work and show as out of date in `openmoat status` and `openmoat doctor` until you run `openmoat init` (ADR-071) ([#772](https://github.com/crocodile-labs/openmoat/pull/772)).
