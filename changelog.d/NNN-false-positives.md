### Fixed
- `df -h ~` and `df /Users/me` no longer ask as a read of the home folder (`home-sweep`): `df` queries the file system holding a path and opens nothing under it; `du` still counts as a read ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- A `~` inside an interpreter's inline program (`perl -0pi -e 's~a~b~s'`) is read as the delimiter or operator it is, not as the home folder or another user's home, and the program word is no longer taken for a file operand ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- `pipe-to-shell` now matches only a consumer that runs its stdin as its program (`| sh`, `| python3`, `| python3 -`, `| node -`, `| perl`, `| source /dev/stdin`, `| xargs sh`), reported as the canonical `<stages> | <interpreter>` pipeline; `curl … | python3 -I -c CODE`, `| node -e CODE`, `| perl -ne CODE`, `| jq` and `| grep` read the download as data and are decided as before without the deny ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- `env | cut -d= -f1`, `env | cut -d = -f 1`, `printenv | sed 's/=.*//'`, `env | sed -E 's/=.*$//'` and `env | awk -F= '{print $1}'` are no longer denied as an environment dump (`env-dump`): the filter keeps the names and drops every value; any other consumer (`| grep`, `| sort`, `| head`, `| cut -d= -f2`, `| base64`, `| tee`) leaves the deny ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- A shell pattern's `*` no longer crosses `;`, `&&`, `||` or `&`, so `git push -u origin b 2>&1 | tail; git for-each-ref --format=…` is no longer denied as a force push (`destructive`) because of the later command's `--format=`; a force push anywhere on the line is still denied by its own command ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- `stops-openmoat` reads a `pkill`/`killall` pattern as the regular expression it is and asks only when it could match the process name `openmoat` or `moat`: `pkill -f latency-compare.py; bash moat-notes/run.sh` and `pkill -f my-server.js` no longer ask, while `pkill -f 'open.*'`, `pkill -f .`, `pkill -f 'o.*t'`, `pkill -x openmoat`, `killall moat` and `pkill -f /usr/local/bin/openmoat` do ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
- A test of whether a secret variable is set is no longer a read of it (`env-secrets`): `[ -n "$GITHUB_TOKEN" ]`, `[ -z … ]`, `test -n`, `[[ -n $X ]]`, `${#X}`, `${X:+set}` and `${X+set}`; `echo $X`, `${X:0:4}`, `y=$X`, `[ "$X" = … ]` and `${X:+$X}` stay denied ([#NNN](https://github.com/crocodile-labs/openmoat/pull/NNN)).
