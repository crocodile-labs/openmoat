### Added
- Crush, in preview: `openmoat init` adds a `PreToolUse` hook named `openmoat` to Crush's global `crush.json` (`~/.config/crush`, `$XDG_CONFIG_HOME/crush` or `CRUSH_GLOBAL_CONFIG`) for Crush 0.63.0 and later, and `openmoat guard --host crush` reads its Claude Code-shaped payload with Crush's own tool names. Crush cannot prompt from a hook, so a review reaches it as a deny that says how to approve the call, and starting a subagent, whose own tool calls fire no hook, needs review. Built from Crush's documentation and source, not yet run against a real `crush`; a hook that fails or times out lets the call run. The default policy protects Crush's global configuration and `crushrc`, and holds a project's `crush.json`, `.crush.json`, `crushrc` and `.crushrc` for review ([#9723](https://github.com/crocodile-labs/openmoat/pull/9723)).
