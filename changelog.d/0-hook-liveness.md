### Added
- `openmoat status`, `openmoat doctor` and `openmoat watch` now say when an agent that runs a hook command seems to have stopped running OpenMoat's hook: when Claude Code, Codex, the Cursor CLI, GitHub Copilot CLI, Gemini CLI or Qwen Code wrote sessions since OpenMoat wrote its hook, its settings changed or it was updated, and no call of its reached OpenMoat, a warning counts the sessions ("ran 3 sessions since …, and OpenMoat saw no call from it: if they used tools, …") and gives the fix: restart the agent, run `openmoat init`, check what turns its hook off, and for Codex trust the hooks in `/hooks`. A session counts once it is ten minutes old; for Cline, goose, Hermes Agent, Antigravity CLI and Crush, whose session files are not known, `doctor` notes only that no call came. `watch` prints one line when an agent's plugin or hook turns missing and one when its calls come back. Nothing is decided from it and no protection level changes. `status --format json` lists the hook agents under `hooks` ([#0](https://github.com/crocodile-labs/openmoat/pull/0)).
