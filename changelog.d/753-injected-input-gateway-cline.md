### Security
- Injected input (ADR-057) is kept for more than Claude Code: the MCP gateway (`openmoat mcp proxy`) keeps what a wrapped server's tool returned, for every agent, under the session of the hook's decision for that call, and the Cline CLI's `PostToolUse` file (OpenMoat's script, which `openmoat init` now writes beside `PreToolUse`) reports what each call returned. A later call of the session that uses a host, path or command that untrusted output named needs review (`injected-input`); after an upgrade, `openmoat status` shows Cline's hook out of date until `openmoat init` adds the file ([#753](https://github.com/crocodile-labs/openmoat/pull/753)).
