### Security
- `openmoat policy check-diff` checks lockfiles as it checks direct dependencies (ADR-125): a new or changed entry whose name is one typo or trick away from a popular package (`diff-package-near-miss`), in `package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`, `Cargo.lock`, `poetry.lock`, `uv.lock` and `go.sum`; an install script the lockfile records for a package, transitive ones included (`"hasInstallScript": true`, `requiresBuild: true`: `diff-install-script`); and a `go.sum` hash changed while the module's version stays (`diff-lock-integrity`). All from the lockfile's text, with no network ([#0](https://github.com/crocodile-labs/openmoat/pull/0)).
