### Security
- `openmoat mcp proxy` for Codex takes only the hook decision with the exact `threadId` and `callId` Codex sends in a call's `_meta`, so one Codex session's identical call can no longer use another session's allow; a call with one id, an empty one or a mismatched pair is refused (ADR-107). The guard writes the MCP decision last, so a call whose audit write failed leaves none behind. When the agent closes the proxy's input, a server that does not exit is sent `SIGTERM` to its process group and killed 5 seconds later (from a contribution by Marlon Costa, [#847](https://github.com/crocodile-labs/openmoat/pull/847)). ([#851](https://github.com/crocodile-labs/openmoat/pull/851))
