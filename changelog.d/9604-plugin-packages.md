### Added
- Packages for each agent's own plugin channel, in preview and not yet listed: a Claude Code plugin with a marketplace file, a Cursor plugin, a Gemini CLI extension, a GitHub Copilot CLI plugin, npm packages for OpenCode and pi, a ClawHub package for OpenClaw, a Hermes Agent catalog plugin and an Antigravity CLI plugin, in `plugins/`, generated from the host specs. None holds a binary or downloads anything: each runs `openmoat guard --host <id> --plugin` from the search path and blocks every call, naming the install command, when there is no `openmoat`; without a policy lock the guard denies and names `openmoat init`. Where `openmoat init`'s own hook is installed and pinned for the agent, the package gives no decision, so each call is decided once, and `openmoat doctor` reports what each package did last (ADR-095) ([#9604](https://github.com/crocodile-labs/openmoat/pull/9604)).
