### Added
- Packages for each agent's own plugin channel, in preview and not yet listed: a Claude Code plugin with a marketplace file, a Cursor plugin, a Gemini CLI extension, a GitHub Copilot CLI plugin, npm packages for OpenCode and pi, a ClawHub package for OpenClaw, a Hermes Agent catalog plugin and an Antigravity CLI plugin, in `plugins/`, generated from the host specs. None holds a binary or downloads anything. Each runs `openmoat guard --host <id> --plugin` with the binary the policy lock pins (`~/.cargo/bin`, Homebrew's folder and the search path only before there is a lock) and blocks every call, naming the install command, when there is none; without a policy lock the guard denies and names `openmoat init`. A package decides only with the default state directory. Where `openmoat init`'s own hook is installed and pinned for the hook file the agent reads, no settings file turns it off and, for pi, OpenCode and OpenClaw, `init`'s plugin has itself reported loading, the package gives no decision, so each call is decided once. The audit log (schema 11) marks the calls a package decided, which never count as `init`'s plugin having loaded. The default policy's `kernel-self` covers the folder each agent keeps OpenMoat's package in, and `openmoat doctor` reports what each package did last (ADR-099) ([#9604](https://github.com/crocodile-labs/openmoat/pull/9604)).
