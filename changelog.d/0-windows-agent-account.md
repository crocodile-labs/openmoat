### Added
- Windows, preview: `openmoat agent-account setup`, run once from an administrator terminal, makes a local account for agents (in no group, interactive logon only, hidden from the sign-in screen, its password encrypted for you with DPAPI) and grants it read on your profile; after that `openmoat run` starts the agent as that account, so Windows refuses its reads of `~/.ssh`, other agents' logins and the other places the policy denies, as well as its writes outside the project. `openmoat agent-account status` exits 1 when the system differs from what setup recorded, and `remove` undoes all of it. Setup and remove are for a person at a terminal, ask for the gate's code when it is set up, and are recorded in the policy-change ledger; on macOS and Linux each exits 64. A run as the account scores at most 70/100: the network is still held by the proxy variables only, and the Windows Filtering Platform filters for the account are the next step (ADR-129) ([#0](https://github.com/crocodile-labs/openmoat/pull/0)).
