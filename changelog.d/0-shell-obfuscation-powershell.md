### Security
- A shell or PowerShell line written to hide what it runs (quotes splitting words, escapes of plain letters, `${!ref}`, `${s:2:3}` cuts, `IFS` changes, `tr` rotations, `` I`nv`oke ``, `[char]` codes, joined strings) is held for review by the new rule `obfuscated`, scored on MITRE DET0505's signals; no everyday command among the benign fixtures and MoatBench's workflows reaches the score. Known `${s:n:m}` cuts, `${!r}` and substitutions that print known text are now followed, so `s=QZcatZQ; ${s:2:3} ~/.ssh/id_rsa` is denied like `cat ~/.ssh/id_rsa` (ADR-116) ([#0](https://github.com/crocodile-labs/openmoat/pull/0)).
- PowerShell commands are read in preview: each simple statement is decided as the POSIX command that does the same, so `Remove-Item -Recurse -Force ~`, `Get-Content $env:USERPROFILE\.ssh\id_rsa` and `iwr URL | iex` are denied, code built at run time is held as `opaque-code`, and `Set-ExecutionPolicy` for the user or the machine is held by `persistence`. A PowerShell line is still never allowed on that reading alone; `pwsh -Command` and `powershell -EncodedCommand` in a POSIX line are read the same way (ADR-116) ([#0](https://github.com/crocodile-labs/openmoat/pull/0)).
