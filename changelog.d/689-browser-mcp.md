### Security
- A browser MCP call that only opens a page (Chrome DevTools MCP `navigate_page` and `new_page`, Playwright MCP `browser_navigate`, Puppeteer `puppeteer_navigate`, Claude in Chrome `navigate`, Browserbase `navigate`) is decided like `WebFetch`: it defers to the agent's own prompt instead of being denied for every unlisted host. A call that sends more than its URL (a script on the page, launch options, headers, a form) stays denied for unlisted hosts, an IP address or single-label host stays `net`, a `localhost` dev server still defers through `local-net`, and `mcp: { browser_open: net }` keeps the old behaviour. A policy whose `defaults.fetch` or `fetch` rules allow a host now allows browser page opens of it too ([#685](https://github.com/crocodile-labs/openmoat/pull/685)).
- A URL is judged by every host a client may read it as reaching, including the URL Standard's reading that browsers and `WebFetch` follow: `WebFetch https://evil.com\@github.com/` was decided as `github.com`, which the default policy allows, and is now also `evil.com`; tabs, newlines, `http:/` with one slash and a percent-encoded host no longer hide a metadata address from `cloud-metadata` ([#685](https://github.com/crocodile-labs/openmoat/pull/685)).
- A `file:` URL in an MCP URL argument is a read of the file it names, so `navigate file:///Users/you/.ssh/id_rsa` is denied by `secrets-paths` instead of deferring; `javascript:`, `data:`, `chrome:` and other URLs that name no network address ask ([#685](https://github.com/crocodile-labs/openmoat/pull/685)).
- New deny group `encoded-egress`: once the session read secret material, a URL a fetch, network or MCP tool opens that carries 80 or more characters of base64 or hex is denied; run `openmoat policy upgrade` to add it to an existing policy ([#685](https://github.com/crocodile-labs/openmoat/pull/685)).
- A browser's screenshot, snapshot or trace tool writes the file its path names, so `take_screenshot {filePath: "~/.zshrc"}` is denied by `shell-rc` ([#685](https://github.com/crocodile-labs/openmoat/pull/685)).
