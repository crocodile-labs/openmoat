### Changed
- Every command shows a verdict with the same mark: `✓ allow`, `→ defer`, `? review`, `✕ deny` (`policy check`, `demo`, `show`, `replay` and `watch`, which showed `·` for a defer). Each mark is one column wide, so `demo`'s table lines up. `audit verify`, `audit anchor` and `provenance --verify` mark a failure `✗`, as `status` and `doctor` do. A script that matched the earlier `⛔`, `❓` or `✔` should match the verdict word instead ([#761](https://github.com/crocodile-labs/openmoat/pull/761)).
- A call that uses what a page or tool result planted gets one `injected-input` reason per source, naming each part once: "the command `…`, the host `…` and the path `…` came from the page fetched from …", where it was one reason per part, each repeating the source ([#761](https://github.com/crocodile-labs/openmoat/pull/761)).
