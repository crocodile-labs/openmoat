### Security
- Under `openmoat run`, tool commands of Claude Code, OpenCode, goose, Hermes Agent, OpenClaw, the Continue CLI and pi no longer receive the run's relay token, and a command cannot read it from the agent that started it (macOS: the sandbox denies `kern.procargs*`; Linux: no grant covers `/proc`, and a wrapped command gets a Landlock layer of its own). Codex, Cursor, GitHub Copilot CLI, Gemini CLI, the Cline CLI and the Antigravity CLI start tool commands in a way OpenMoat cannot yet tell from their hooks, so theirs still do. `openmoat doctor` names both groups and `openmoat bench --report` tries the attack (ADR-075) ([#774](https://github.com/crocodile-labs/openmoat/pull/774)).
